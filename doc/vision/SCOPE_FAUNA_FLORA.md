## I. Escopo Ampliado

O Projeto Thothia contempla toda forma de vida observável na região de
Governador Celso Ramos / Palmas – SC, organizando-as em duas macrodivisões:

1. **Fauna** — conjunto dos animais observados (vertebrados e invertebrados);
2. **Flora** — conjunto das plantas, fungos e algas registradas.

---

## II. Classificação Biológica

Cada espécie será classificada conforme o sistema **taxonômico hierárquico
universal**, com os seguintes níveis:

| Nível   | Exemplo                                                   |
| ------- | --------------------------------------------------------- |
| Reino   | Animalia / Plantae / Fungi                                |
| Filo    | Chordata / Arthropoda / Magnoliophyta                     |
| Classe  | Aves / Mammalia / Insecta / Liliopsida                    |
| Ordem   | Passeriformes / Carnivora / Fabales                       |
| Família | Tyrannidae / Canidae / Fabaceae                           |
| Gênero  | _Pitangus_ / _Canis_ / _Inga_                             |
| Espécie | _Pitangus sulphuratus_ / _Canis familiaris_ / _Inga vera_ |

---

## III. Categorias Ecológicas

Cada espécie catalogada receberá também um **status ecológico**:

- **Nativa:** ocorre naturalmente na região.
- **Endêmica:** exclusiva daquela região.
- **Exótica:** originária de outro ecossistema.
- **Invasora:** espécie exótica que causa impacto ambiental.
- **Introduzida:** trazida por ação humana, sem necessariamente causar danos.

---

## IV. Atributos do Registro

Cada item do catálogo incluirá:

- 🏷️ Nome comum e científico
- 🧬 Classificação taxonômica completa
- 📸 Imagem (fotografia autoral)
- 📅 Data e hora do registro
- 📍 Local aproximado
- 🌱 Status ecológico
- 🧠 Observações e curiosidades
- 🔗 Referências científicas utilizadas

---

## V. Escalabilidade

O escopo foi projetado para permitir:

- Expansão geográfica futura (novas regiões ou biomas);
- Inserção de novas categorias (fungos, microrganismos, etc.);
- Integração com IA de reconhecimento e APIs abertas de biodiversidade (ex:
  GBIF, iNaturalist).
